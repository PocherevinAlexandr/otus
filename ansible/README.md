# Отчет по домашнему заданию: Развертывание Nginx с помощью Vagrant и Ansible

---

## Описание реализации

В рамках выполнения домашнего задания был подготовлен автоматизированный стенд для развертывания веб-сервера Nginx на базе **Ubuntu 22.04 LTS**. Сценарий полностью удовлетворяет всем заявленным требованиям:

1. **Использование модулей пакетов:** Для управления установкой применен модуль `ansible.builtin.apt` с предварительным обновлением кэша репозиториев (`update_cache: true`).
2. **Шаблонизация Jinja2:** Главный конфигурационный файл веб-сервера формируется динамически на основе шаблона `nginx.conf.j2`. Порт прослушивания вынесен в переменную `{{ nginx_port }}`.
3. **Режим автозапуска:** С помощью модуля `ansible.builtin.systemd` для службы Nginx жестко зафиксировано состояние `enabled: true`.
4. **Механизм Notify / Handlers:** Старт и перезапуск веб-сервера при первичном развертывании или обновлении конфигурационных файлов завязаны на триггер `notify`, вызывающий обработчик `restarted`.
5. **Нестандартный порт:** Сайт развернут и слушает порт **8080**, значение которого передается через Ansible-переменные.

---

## Инструкция по запуску стенда

1. Склонируйте репозиторий с проектом.
2. Убедитесь, что у вас установлены Vagrant и VirtualBox.
3. Запустите сборку стенда из корневой директории проекта:
   ```bash
   vagrant up
   ```
4. В процессе загрузки Vagrant автоматически поднимет виртуалку и запустит Ansible плейбук локально внутри гостевой ОС.

---

## Демонстрация работоспособности

После успешного выполнения команды `vagrant up` веб-сервер автоматически становится доступен с хостовой машины (благодаря правилу `forwarded_port` в Vagrantfile).

Проверка доступности сайта с локального компьютера:
```bash
curl -I http://localhost:8080
```
