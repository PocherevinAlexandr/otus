# ДЗ: Настройка центрального сервера для сбора логов

Цель:

научится проектировать централизованный сбор логов;
рассмотреть особенности разных платформ для сбора логов.

Описание/Пошаговая инструкция выполнения домашнего задания:

🎯 Что нужно сделать?

    Поднимаем две машины — web и log.
    На web поднимаем nginx.
    Настраиваем центральный лог-сервер на любой системе по выбору:

    journald;
    rsyslog;
    elk.

    Настраиваем аудит, который будет отслеживать изменения конфигураций nginx.

    Все критичные логи с web должны собираться и локально и удаленно.
    Все логи с nginx должны уходить на удаленный сервер (локально только критичные).
    Логи аудита должны также уходить на удаленную систему.



Проект разворачивает две виртуальные машины (`web` и `log`). 


## Как запустить:
1. Выполните команду в корне проекта:
   ```bash
   vagrant up
   ```

## Как проверить работу:
1. Зайдите на `web` сервер и сгенерируйте событие для Nginx и Auditd:
   ```bash
   vagrant ssh web
   curl localhost
   sudo touch /etc/nginx/test_audit.conf
   exit
   ```
2. Зайдите на `log` сервер и проверьте, что логи прилетели:
   ```bash
   vagrant ssh log
   ls -la /var/log/rsyslog/web/
   cat /var/log/rsyslog/web/nginx_access.log
   cat /var/log/rsyslog/web/audisp-syslog.log
   ```
