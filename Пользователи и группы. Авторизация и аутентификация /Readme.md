## Цель: научиться создавать пользователей и добавлять им ограничения;

## Описание/Пошаговая инструкция выполнения домашнего задания:

🎯 Что нужно сделать?

Ограничить доступ к системе для всех пользователей, кроме группы администраторов, в выходные дни (суббота и воскресенье), за исключением праздничных дней.

⭐️ Задание повышенной сложности

Предоставить определённому пользователю доступ к Docker и право перезапускать Docker-сервис.

>[!NOTE]
>В Vagrant файле для корректной работы в моей среде необходимо добавить корпоративный сертификат и прокинуть DNS
>раскомментировать в блоке 1, пункт === 1. Интеграция корпоративного SSL-сертификата === и пункт === 2. Настройка DNS-серверов ===


## Демонстрация работоспособности

В пятницу вход выполнен успешно со всех учёток, в субботу вход под пользователем otus заблокирован так как он не в группе admin
>[!NOTE]
>Время сбивалось автоматически с хоста, пришлось менять время на реальном хосте.

1. otus без sudo (docker run ...) — РАБОТАЕТ, так как он в группе docker.
2. otusadm без sudo — НЕ РАБОТАЕТ (Permission denied), так как его нет в группе docker.
3. otusadm с sudo — РАБОТАЕТ, так как группа admin в файле /etc/sudoers.
