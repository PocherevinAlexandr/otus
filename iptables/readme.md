# Домашнее задание Сценарии iptables
## Цель: Написать сценарии iptables.
## Описание/Пошаговая инструкция выполнения домашнего задания:
 Что нужно сделать?

   1. реализовать knocking port
      centralRouter может попасть на ssh inetrRouter через knock скрипт (пример в материалах).

   2. добавить inetRouter2, который виден(маршрутизируется (host-only тип сети для виртуалки)) с хоста или форвардится порт через локалхост.
   3. запустить nginx на centralServer.
   4. пробросить 80й порт на inetRouter2 8080.
   5. дефолт в инет оставить через inetRouter.
   *. Реализовать проход на 80й порт без маскарадинга

Формат сдачи ДЗ - vagrant + ansible

## Как проверить работу стенда?

1. Проверка Port Knocking (с centralRouter на inetRouter):bash
 Попытка зайти напрямую — закроется по таймауту
ssh 192.168.255.1

 Перебираем порты «стука» (чистым bash или nc)
timeout 1 bash -c 'echo > /dev/tcp/192.168.255.1/7001'
timeout 1 bash -c 'echo > /dev/tcp/192.168.255.1/7002'

У вас есть 10 секунд, чтобы успешно подключиться:
ssh user@192.168.255.1
2. Проверка работы Nginx без маскарадинга (с хост-машины):
Выполните запрос с вашего ПК (хоста) на Host-only IP-адрес inetRouter2:bash
curl http://192.168.56.7

Запрос успешно пройдет. Если зайти на саму виртуалку centralServer и проверить логи Nginx (tail -n 5 /var/log/nginx/access.log), вы увидите там реальный IP-адрес вашего хоста (например, 192.168.56.1), а не IP-адрес роутера! Это доказывает выполнение условия «без маскарадинга».
