 ## Описание архитектуры стенда

Стенд состоит из двух виртуальных машин, разворачиваемых в изолированной внутренней сети VirtualBox (`pxe_net`):
1. **pxeserver (`192.168.56.10`)**: Сервер инфраструктуры. Содержит DHCP-сервер, TFTP-сервер, веб-сервер Nginx для отдачи файлов конфигураций Autoinstall (Cloud-init) и NFS-сервер для монтирования корневой файловой системы инсталлятора.
2. **pxeclient**: Пустая целевая машина (или машина с предустановленной ОС), которая загружается по сети через PXE, выполняет автоматическую разметку диска, ставит ОС и перезапускается в готовую систему.

### Поддерживаемые режимы загрузки:
* **Legacy BIOS**: Загрузка с помощью `pxelinux.0` (Syslinux).
* **UEFI**: Безопасная загрузка (Secure Boot) с использованием `shimx64.efi.signed` и GRUB2 (`grubx64.efi.signed`).

## Структура репозитория

* `Vagrantfile` — Описание конфигурации виртуальных машин VirtualBox.
* `playbook.yml` — Ansible-плейбук для автоматической настройки PXE-сервера.
* `dhcpd.conf.j2` — Шаблон DHCP-сервера с динамическим определением архитектуры клиента (BIOS/UEFI).
* `default.j2` — Шаблон загрузочного меню Syslinux для BIOS клиентов.
* `grub.cfg.j2` — Шаблон загрузочного меню GRUB для UEFI клиентов.
* `user-data.j2` — Файл конфигурации автоустановщика Ubuntu Autoinstall (Cloud-init).

## Порядок развертывания стенда

### Шаг 1. Предварительные требования
Убедитесь, что на хост-машине установлены:
* VirtualBox (версии 7.0+)
* Vagrant (версии 2.3+)
* Плагин Ansible на хосте (или Ansible внутри базового бокса)

### Шаг 2. Запуск инфраструктуры
Для развертывания стенда выполните в корневой директории проекта:
```bash
vagrant up
```
*Vagrant поднимет машину `pxeserver`, запустит Ansible-плейбук, который установит необходимые пакеты, скачает официальный ISO-образ Ubuntu 24.04, распакует ядро (`vmlinuz`) и `initrd`, настроит службы Nginx, NFS, TFTP и DHCP. После этого автоматически включится `pxeclient`.*

## Тестирование различных режимов (BIOS и UEFI)

### Тестирование Legacy BIOS (По умолчанию)
По умолчанию в `Vagrantfile` клиент настроен на работу в стандартном режиме BIOS.
1. При первой загрузке `pxeclient` обращается к DHCP, получает IP и скачивает `pxelinux.0`.
2. Меню по умолчанию предлагает пункт локальной загрузки, однако GRUB/PXE автоматически инициируют сетевую установку, если жесткий диск пуст.
3. Происходит автоматическая установка Ubuntu 24.04.

### Тестирование UEFI (Задание со звездочкой)

>[!WARNING]
>у меня не заработало по всей видимости ограничения virtualbox и возможно сам образ не правильный для загрузки

Для проверки работы сетевой загрузки через UEFI:
1. Откройте `Vagrantfile`.
2. В блоке настроек провайдера машины `pxeclient` найдите и раскомментируйте строчку:
   ```ruby
   vb.customize ["modifyvm", :id, "--firmware", "efi"]
   ```
3. Уничтожьте старого клиента и запустите его заново:
   ```bash
   vagrant destroy pxeclient -f
   # Пересборка сервера не требуется, достаточно запустить клиента
   vagrant up pxeclient
   ```
4. Клиент получит файл `bootx64.efi`, загрузит меню GRUB и запустит автоустановку Ubuntu по сети в режиме UEFI EFI-системы.

## Защита от бесконечного цикла установки (Разрыв петли PXE)

Поскольку в VirtualBox сетевой интерфейс (`net`) назначен приоритетным устройством загрузки, после окончания установки и перезагрузки машина могла бы снова начать установку ОС с нуля.

После установки вместо перезагрузки необходимо сделать выключение и сменить порядок загрузки.
